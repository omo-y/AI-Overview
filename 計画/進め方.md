まとめ

OpenAI APIを使わずにローカルLLMで作る場合は、

API料金を抑えられる
データを外部に送らない
自分用・社内用には強い

一方で、

公開SaaSにはやや不向き
品質と速度がPC性能に依存
同時利用に弱い
運用負荷が高い

という特徴があります。

そのため、現実的には、

自分用・検証用 → ローカルLLM
一般公開SaaS → OpenAI API
企業向け高セキュリティ版 → ローカルLLM

と分けて考えるのがよいです。
